# To Do List App

## Interactive Quiz Application

A modern dark-mode to-do web application built with HTML, CSS, and JavaScript featuring a glassmorphism UI and responsive Gen-Z inspired design.

---

## Features

* Add and manage daily tasks easily
* Set date and time for each task
* Edit and delete tasks anytime
* Mark tasks as completed with animated effects
* Fully responsive design for desktop and mobile devices

CSS
JavaScript
